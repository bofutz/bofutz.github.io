# 波幅探长 v5.1 二次深度优化说明与部署指南

## 一、本次 8 项核心升级与修复清单

1. **修复后台优惠码保存报错 + 前台双位置优惠码输入核销**
   - **后台修复**：修复 `/api/admin/promos` 在旧表缺失列、空日期（`NaN`）或同名历史软删优惠码触发 `UNIQUE` 冲突时的报错；启动迁移自动补齐 `promo_codes` 全部字段，支持重复编码自动覆盖激活。
   - **前台升级**：在「赞助标的」页面的**待赞助结算栏**和**扫码支付弹窗**中均内置了醒目的优惠码输入框，支持一键校验、实时抵扣并重算精准浮动金额。

2. **数据看板股票/ETF代码后增加 `(t+0)` / `(t+1)` 交易制度标识**
   - 自动根据代码前缀（如 `513/159920/518880/511` 等）及名称关键字（跨境、港股、恒生、纳指、黄金、债券、货币、原油、日经等）精准识别 `(t+0)` 与 `(t+1)`，并以醒目徽章展示在代码右侧。
   - 后台「默认监控列表」与「赞助标的」均支持手动指定或修改每个标的的交易规则（`自动识别 / 强制(t+0) / 强制(t+1)`）。

3. **优化导航栏，消除重复入口（对应截图一）**
   - **桌面端主导航**：精简为 `数据看板`、`赞助标的`、`图表说明` 三大核心公共导航。
   - **右侧个人菜单**：集中收纳 `我的赞助（置顶/修改标的）`、`个人中心（昵称/订单/安全）`、`客服工单（问题反馈/广播）` 与 `退出登录`，彻底消除顶部与下拉框重复出现「我的赞助」和「客服工单」的问题。

4. **赞助会员专属看板置顶 + 其他用户排在前三下面**
   - **赞助者本人视角**：自己赞助的有效标的在数据看板**默认置顶（排在第一梯队，甚至高于免费 TOP 3）**，并带有醒目的 `★ 我的赞助置顶` 翡翠绿标识。
   - **其他用户/访客视角**：排序优先级严格为 **`免费 TOP 3` → `会员赞助标的` → `个人收藏标的` → `其余普通标的`**，让赞助标的获得极佳的全站曝光。

5. **修复数据看板显示「热心会员 赞助」而非「昵称 赞助」的问题（对应截图二）**
   - **后端多源兜底**：后端 `/api/watchlist` 与 `/api/sponsor/active` 支持直接读取 `symbol_sponsors.sponsor_nickname` 专属署名列，并关联 `users.nickname`，杜绝因关联为空回退成「热心会员」。
   - **前台发起赞助必填昵称**：用户在发起赞助支付前，若尚未设置昵称，可在清单栏直接填写「赞助展示昵称」，支付提交时自动同步保存至账号与订单。
   - **后台直接改署名**：管理员可在后台「赞助标的」页面直接新增或修改任意赞助标的的展示昵称与交易规则，前台数据看板即刻同步显示 `❤️ 昵称 赞助`。

6. **全面同步优化手机端（Mobile）显示体验**
   - **数据看板表格**：优化手机端首列宽度与 sticky 阴影，代码、`(t+0)/(t+1)` 与 `❤️ 昵称 赞助` 标签紧凑自适应不撑破行高；支持筛选胶囊横向丝滑滚动。
   - **管理后台手机端适配**：`admin.html` 新增移动端汉堡菜单与抽屉式侧边栏，手机上也能流畅审核订单、管理赞助与回复工单。

7. **开发者视角新增实用功能**
   - **看板快捷筛选胶囊栏**：支持一键筛选 `全部`、`⚡ T+0 可日内回转`、`❤️ 会员赞助`、`🔥 最新异动`、`★ 我的自选/赞助`。
   - **代码一键复制**：点击数据看板上的 6 位标的代码即可一键复制到剪贴板，方便直接切到交易软件下单。
   - **后台手动添加/编辑赞助标的**：管理员无需走前台支付流程即可在后台直接新增、延期或编辑赞助标的、署名与交易规则。

8. **整站代码精简与性能优化**
   - 清理原 `all_code.txt` 末尾意外重复拼接的文件块，体积减少约 35%。
   - `vip-api.js` 引入 Isolate 级表结构初始化缓存（` schemaInitialized `）与 `ctx.waitUntil` 异步过期工单清理，大幅降低每次 API 请求的 D1 数据库开销，响应更迅速。
